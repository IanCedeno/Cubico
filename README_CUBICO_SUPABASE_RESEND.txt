CÚBICO - Variables de entorno

En Netlify > Project configuration > Environment variables crea estas variables:

SUPABASE_URL = pega aquí tu Project URL de Supabase
SUPABASE_ANON_KEY = pega aquí tu anon public key de Supabase
RESEND_API_KEY = pega aquí tu API key de Resend

IMPORTANTE:
- No pegues valores reales dentro de archivos JS, README o HTML.
- Los valores reales van solo en Netlify Environment variables.
- Después de guardar variables, vuelve a hacer Deploy.
